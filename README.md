# Errand

Codexに小さな仕事を頼むためのGTKチャットアプリです。
LinuxではGNOMEのトップバーから、macOSではアプリとして起動できます。
翻訳、言葉の相談、計算、ローカルファイルの確認や加工などを、数回の会話で依頼できます。
Codex CLIの `app-server` に接続し、既存のログインと設定を利用します。

## 主な機能

- トップバーのアイコンと設定可能なショートカットから起動
- タブごとの独立した会話、下書き、モデル・推論の強さ、承認方法
- Markdown、表、コピー可能なコードブロック、基本的なLaTeX数式の表示
- ローカルファイルのドラッグアンドドロップ
- 作業の中断、実行内容や追加権限の承認
- 会話全文または引き継ぎ用要約のコピー
- 未ログイン時のログイン手順の案内

## 必要な環境

- Linuxのトップバー連携にはGNOME Shell 50（現在の対応バージョン）
- Python 3、PyGObject、GTK 4、libadwaita、PyCairo、PangoCairo
- `app-server` に対応するCodex CLIと、利用するモデルの認証

macOSの試用版はPython・GTKを同梱し、Codexは必要な場合だけ初回にアプリから取得します。
macOS 15以降と、ご自身のCodexを利用できるChatGPTアカウントが必要です。

数式描画にTeX環境は不要です。ファイルを扱う際に必要なツールは依頼内容により異なります。

## 起動とインストール

リポジトリのルートで、チャット画面だけを起動できます。

```bash
python3 app.py
```

Codexが見つからない場合は、実行ファイルを指定してください。

```bash
python3 app.py --codex /absolute/path/to/codex
```

未ログインの場合は、アプリの「ChatGPTにログイン」からブラウザでログインできます。
既存のCodexログインは引き続き利用します。

GNOME拡張のZIPを入手したら、Terminalでインストールします。
以下のパスは、ダウンロードしたZIPの場所に置き換えてください。
ソースから生成する手順は [開発ガイド](CONTRIBUTING.md) にあります。

```bash
gnome-extensions install /path/to/errand@jidaikobo.shibata.zip
```

Waylandではログアウトしてログインし直し、ExtensionsまたはExtension Managerから有効化します。
拡張の設定画面では、起動ショートカットとCodex実行ファイルの場所を変更できます。

## macOSの試用版

配布用ZIPはPython・GTKを同梱します。受け取った人がTerminalやHomebrewで
環境を準備する必要はありません。Apple Silicon版とIntel版を別々のZIPとして生成します。
ZIPを展開し、`Errand.app` を「アプリケーション」へ移して起動してください。
「動作環境を準備する」が表示されたら、そのボタンで必要なCodexを取得・検証します。
取得中の進捗、中止、失敗後の再試行に対応します。既存のCodexが使える場合は取得を省略します。
未ログインなら、アプリの「ChatGPTにログイン」からブラウザでログインします。

Appleによる公証を受けていない試用版のため、初回の警告と許可手順を含む
[導入案内](distribution/START_HERE.html) をZIPに添えます。
配布者用の [Slack向けの案内文](distribution/SLACK_MESSAGE.txt) は試用ZIPの外に用意しています。
動作確認の報告テンプレートは導入案内に含めています。
依存の対応ソースと再ビルド用ファイルは、試用ZIPと同じ配布場所にある別の対応ソースZIPに収録します。
試用ZIPは `Errand-Trial-AppleSilicon.zip` と `Errand-Trial-Intel.zip`、
対応ソースは `Errand-Sources-AppleSilicon.zip` と `Errand-Sources-Intel.zip` の計4ファイルです。
試用者は自分のMacに合うTrial ZIPだけを展開します。
対応ソースは別の保存先へ置き、アプリの配布投稿に取得リンクを載せる形でも提供できます。
公開された配布先はまだありません。

開発用のソース版は引き続きHomebrewに依存します。同梱版とソース版の生成方法は
[開発ガイド](CONTRIBUTING.md) を参照してください。

生成した `Errand.app` はFinderから開けます。
macOSではCtrlに加えて⌘+Enterで送信、⌘+Tでタブ作成、⌘+Wでタブを閉じ、
⌘+Qまたはアプリメニューから終了できます。
メニューバー常駐は未実装です。起動ショートカットはErrandが起動している間に使えます。

## 環境設定

ウィンドウ右上の三本線ボタン（環境設定）から設定を開けます。
「一般」では文字サイズとCodexのパス、「キーボード・ショートカット」では起動、
左右のタブ移動、新規タブ、発言移動などのキーを変更できます。
各キーは無効化したり、既定値へ戻したりできます。アプリ内でキーが重複すると保存時に知らせます。
Ctrl+,（macOSでは⌘+,）でも開けます。変更後は「保存」を押してください。
文字サイズは表示中の会話にも反映し、Codexのパスは新しいタブから適用します。
Ctrl++／Ctrl+-で1ptずつ拡大・縮小、Ctrl+0で標準の11pt（100%）に戻せます。
Ctrl+=でも拡大でき、macOSではCommandキーでも操作できます。変更したサイズは保存されます。
パスを空欄にするとCodexを自動で検索します。

GNOMEでは拡張の設定画面と起動ショートカット・Codexのパス・文字サイズを共有します。
起動ショートカットはGNOME拡張を有効にして使ってください。
macOSではErrandが起動している間、他のアプリからもウィンドウを呼び出せます。
終了したアプリを起動するキーではありません。英字・数字・Fキーなどに対応し、
英数字のキー位置は標準US配列を基準にします。
ほかのアプリと競合して登録できない場合は、環境設定にエラーを表示します。
macOSでの起動キーの実機動作は確認待ちです。
OSが先に受け取るキーはErrandに届きません。GNOMEのワークスペース操作などと
競合する場合は、Errand側で別のキーを設定してください。OSの割り当ては変更しません。

## 操作

以下は既定のキーです。設定したアプリ内のキーは保存後すぐに反映します。

| 操作 | 既定のキー |
| --- | --- |
| 送信 | Ctrl+Enter |
| 前／次の発言へ | Ctrl+Alt+↑／↓ |
| 最初の発言へ | Ctrl+Alt+Shift+↑ |
| 最新へ移動して自動追従 | Ctrl+Alt+Shift+↓ |
| フォーカス移動 | Tab／Shift+Tab |
| 送信済みの依頼を呼び出す（入力欄が空のとき） | ↑／↓ |
| 環境設定 | Ctrl+, |
| 文字を拡大／縮小 | Ctrl++／Ctrl+- |
| 標準の文字サイズ（100%） | Ctrl+0 |
| 新しいタブ | Ctrl+T |
| 左／右のタブへ | Ctrl+PageUp／PageDown、Ctrl+Shift+Tab／Ctrl+Tab |
| タブを閉じる | Ctrl+W |
| アプリ全体を終了 | Ctrl+Q |
| ウィンドウを隠す | Esc |
| 入力欄の先頭／末尾 | Ctrl+Home／End、Ctrl+↑／↓ |

ウィンドウの閉じるボタンは画面を隠す操作です。作業とタブは維持されます。
新しいタブでは、小仕事の例をランダムに1つ表示します。入力中に自動で切り替わりません。
送信後は実行状況へ切り替わり、エラーやログイン案内は例より優先して表示します。
回答の受信中でも上へスクロールすると末尾への自動追従を止め、末尾に戻ると再開します。
会話欄と状態表示の間の二重上・上・下・二重下ボタンで、最古・前・次・最新へ移動できます。
「あなた」「Codex」の発言を単位に移動し、過去への移動では自動追従を止めます。
最新ボタンは会話の末尾へ移動し、回答の自動追従も再開します。
移動先の発言全体が一度だけ少し薄くなり、薄い状態を0.2秒保ってから約0.6秒で元に戻ります。
キーボードフォーカスは操作ボタンに残します。
再起動にはCtrl+Qで終了してから起動してください。
タブを閉じると、その会話と接続を終了します。閉じた会話は復元できません。

入力欄が空のとき、↑でこのタブの送信済みの依頼を呼び出せます。
呼び出した状態では↑／↓で履歴を移動でき、最新より先へ↓を押すと空欄に戻ります。
編集を始めると通常のカーソル操作に戻ります。履歴はタブを閉じると消え、ファイルの添付は復元しません。

ファイルはドロップするか、依頼文に絶対パスを書いて指定できます。
ドロップ時にはファイル内容を読み込まず、送信時に対象の絶対パスを依頼へ添えます。
会話中のモデル・推論の強さの変更は、次の送信から適用されます。

「会話について」から会話全文や引き継ぎ用要約をコピーできます。

栞アイコンの「定番のお願い」から、名前を付けた依頼文を保存・呼び出しできます。
「今の入力を保存…」で登録し、「管理…」で追加・編集・削除します。
呼び出した依頼文は入力欄に入るだけで、自動送信しません。
入力中の文章や添付ファイルがある場合、または作業中の場合は新しいタブに開きます。
保存するのは名前と依頼文だけです。添付ファイル・モデル・承認方法は保存しません。
定番のお願いはローカルの設定領域に保存し、Errandを終了しても残ります。
要約は別の一時的な会話で生成し、正常完了した場合だけコピーします。
要約生成にも通常のモデル利用が発生します。

## 承認と会話の扱い

会話の作業場所は一時ディレクトリで、初期状態は読み取り専用です。
既定の承認方法は「自分で承認」です。「自動レビュー」もタブごとに選べますが、
すべての操作を無条件で許可する設定ではありません。
追加権限は、要求された範囲を今回の作業または現在のタブに限って許可できます。
既存ファイルを残すようモデルに指示しますが、書き込み許可後の上書きを技術的に保証するものではありません。

Codexのサンドボックスにはネットワークアクセスを許可しない設定を渡します。
モデルとの通信や、既存のCodex設定に登録したMCPなどのツールまで遮断するものではありません。
ErrandはCodexの認証情報を独自に保存せず、Codexの設定ファイルも編集しません。

Errand独自の会話保存はなく、Codexのスレッドには `ephemeral: true` を指定します。
これはCodexの状態DB・診断ログ・サービス側の記録まで消去する機能ではありません。
必要な会話は、終了前にコピーしてください。

## 表示の制限

Markdownは限定的な対応で、完全なCommonMark互換ではありません。
HTMLや外部画像は実行・自動取得しません。
数式は分数、平方根、上付き・下付き、基本演算記号などに対応します。
行列、独自マクロ、表セル内の数式などは未対応です。
描画できない数式は元の記法を表示します。

開発・ビルド・テストについては [開発ガイド](CONTRIBUTING.md) を参照してください。
