# Errand

CodexやGeminiに小さな仕事を頼むためのGTKチャットアプリです。
LinuxではGNOMEのトップバーから、macOSではアプリとして起動できます。
翻訳、言葉の相談、計算、ローカルファイルの確認や加工などを、数回の会話で依頼できます。
Codex CLIの `app-server` に接続し、既存のログインと設定を利用します。
GeminiはAPIキーとGemini CLIで接続し、会話・要約・ファイル操作・コマンド実行を利用できます。

## 主な機能

- トップバーのアイコンと設定可能なショートカットから起動
- タブごとの独立した会話、下書き、モデル・推論の強さ、承認方法
- Markdown、表、コピー可能なコードブロック、基本的なLaTeX数式の表示
- ローカルファイルのドラッグアンドドロップ
- 作業の中断、実行内容や追加権限の承認
- 会話全文または引き継ぎ用要約のコピー
- 未ログイン時のログイン手順の案内

## 必要な環境

- Linuxのトップバー連携にはGNOME Shell 50（現在の対応バージョン）
- Python 3、PyGObject、GTK 4、libadwaita、PyCairo、PangoCairo
- Codexを使う場合：`app-server` に対応するCodex CLIと、利用するモデルの認証
- Geminiを使う場合：Gemini APIキーと、ACPに対応するGemini CLI

macOSの試用版はPython・GTKを同梱し、Codexは必要な場合だけ初回にアプリから取得します。
macOS 15以降と、ご自身のCodexを利用できるChatGPTアカウントが必要です。

数式描画にTeX環境は不要です。ファイルを扱う際に必要なツールは依頼内容により異なります。

## 起動とインストール

リポジトリのルートで、チャット画面だけを起動できます。

```bash
python3 app.py
```

Codexが見つからない場合は、実行ファイルを指定してください。

```bash
python3 app.py --codex /absolute/path/to/codex
```

未ログインの場合は、アプリの「ChatGPTにログイン」からブラウザでログインできます。
既存のCodexログインは引き続き利用します。

GNOME拡張のZIPを入手したら、Terminalでインストールします。
以下のパスは、ダウンロードしたZIPの場所に置き換えてください。
ソースから生成する手順は [開発ガイド](CONTRIBUTING.md) にあります。

```bash
gnome-extensions install /path/to/errand@jidaikobo.shibata.zip
```

Waylandではログアウトしてログインし直し、ExtensionsまたはExtension Managerから有効化します。
拡張の設定画面では、起動ショートカットとCodex実行ファイルの場所を変更できます。

## macOSの試用版

配布用ZIPはPython・GTKを同梱します。受け取った人がTerminalやHomebrewで
環境を準備する必要はありません。Apple Silicon版とIntel版を別々のZIPとして生成します。
ZIPを展開し、`Errand.app` を「アプリケーション」へ移して起動してください。
「動作環境を準備する」が表示されたら、そのボタンで必要なCodexを取得・検証します。
取得中の進捗、中止、失敗後の再試行に対応します。既存のCodexが使える場合は取得を省略します。
未ログインなら、アプリの「ChatGPTにログイン」からブラウザでログインします。

Appleによる公証を受けていない試用版のため、初回の警告と許可手順を含む
[導入案内](distribution/START_HERE.html) をZIPに添えます。
配布者用の [Slack向けの案内文](distribution/SLACK_MESSAGE.txt) は試用ZIPの外に用意しています。
動作確認の報告テンプレートは導入案内に含めています。
依存の対応ソースと再ビルド用ファイルは、試用ZIPと同じ配布場所にある別の対応ソースZIPに収録します。
試用ZIPは `Errand-Trial-AppleSilicon.zip` と `Errand-Trial-Intel.zip`、
対応ソースは `Errand-Sources-AppleSilicon.zip` と `Errand-Sources-Intel.zip` の計4ファイルです。
試用者は自分のMacに合うTrial ZIPだけを展開します。
対応ソースは別の保存先へ置き、アプリの配布投稿に取得リンクを載せる形でも提供できます。
公開された配布先はまだありません。

開発用のソース版は引き続きHomebrewに依存します。同梱版とソース版の生成方法は
[開発ガイド](CONTRIBUTING.md) を参照してください。

生成した `Errand.app` はFinderから開けます。
macOSではCtrlに加えて⌘+Enterで送信、⌘+Tでタブ作成、⌘+Wでタブを閉じ、
⌘+Qまたはアプリメニューから終了できます。
メニューバー常駐は未実装です。起動ショートカットはErrandが起動している間に使えます。

## 環境設定

ウィンドウ右上の三本線ボタン（環境設定）から設定を開けます。
「一般」では文字サイズ・AIの選択・接続設定、「キーボード・ショートカット」では起動、
左右のタブ移動、新規タブ、発言移動などのキーを変更できます。
各キーは無効化したり、既定値へ戻したりできます。アプリ内でキーが重複すると保存時に知らせます。
Ctrl+,（macOSでは⌘+,）でも開けます。変更後は「保存」を押してください。
文字サイズは表示中の会話にも反映し、Codexのパスは新しいタブから適用します。
Ctrl++／Ctrl+-で1ptずつ拡大・縮小、Ctrl+0で標準の10pt（100%）に戻せます。
Ctrl+=でも拡大でき、macOSではCommandキーでも操作できます。変更したサイズは保存されます。
パスを空欄にするとCodexを自動で検索します。

GNOMEでは拡張の設定画面と起動ショートカット・Codexのパス・文字サイズを共有します。
起動ショートカットはGNOME拡張を有効にして使ってください。
macOSではErrandが起動している間、他のアプリからもウィンドウを呼び出せます。
終了したアプリを起動するキーではありません。英字・数字・Fキーなどに対応し、
英数字のキー位置は標準US配列を基準にします。
ほかのアプリと競合して登録できない場合は、環境設定にエラーを表示します。
macOSでの起動キーの実機動作は確認待ちです。

## Geminiを使う

環境設定の「新しいタブで使うAI」を「Gemini」に変更して保存し、新しいタブを開きます。
既存のタブは接続先・会話・下書きを維持します。CodexとGeminiの間で会話は自動転送しません。
既定のAIは引き続きCodexです。以前の会話専用Gemini設定もCLI接続として読み込みます。

Gemini CLI 0.66.0で接続を検証しています。インストール済みのCLIをPATH、Homebrew、nvmなどから
検索します。見つからない場合は環境設定の「Gemini CLI実行ファイルの絶対パス」に指定してください。
CLIの自動取得は行いません。

ファイルをドロップして送信すると、CLIへファイル参照として渡します。CLIがアクセス確認を
求めた場合は、対象を確認して「今回だけ許可」「拒否」「作業を中止」から選びます。
ファイルの作成・変更やコマンド実行でも、CLIの確認要求を同じ画面に表示します。
操作の説明・差分・パスなど、CLIが提供した情報は「詳細」で確認できます。
Codexと同じタブ・入力・進捗・中断・コピー・回答時間・要約の操作を使えます。
モデル選択メニューの承認方法で、Gemini CLI標準の次のモードを選べます。

- 「自分で承認」：CLIが必要とする操作を確認します（初期値）。
- 「編集を自動承認」：編集ツールを自動承認し、コマンド実行などは確認します。
- 「全操作を自動承認（YOLO）」：コマンド実行なども自動承認します。

自動承認の2モードでは、その依頼に添付したファイルの領域外読み取り確認も自動許可します。
添付していないファイルの特別なアクセス確認は対象外です。
これはAIによる安全審査ではなく、CLIの承認モードです。CLIのアクセス制約や拒否規則は残ります。
作業中は変更できず、選択は次の依頼からこのタブだけに適用します。
新しいタブは「自分で承認」に戻り、Codexの自動レビュー設定は変更しません。
要約用の別接続は手動モード・ツール無効のままです。
CLIに渡す依頼文がスラッシュ等で始まっても、CLIコマンドとして実行せず通常の文章として扱います。

この接続はCLIの承認機構を使い、Codexと同じOSサンドボックスを実装するものではありません。
作業領域外のアクセスはCLIのツール・確認方針にも従います。成果物を残す場合は保存先を
絶対パスで指定してください。タブ専用の一時領域内のファイルは、タブを閉じると削除します。
CLIの会話・認証選択・許可設定もタブ専用領域に隔離し、通常の終了時に破棄します。
既存のCLI設定や恒久的な許可は変更しません。キーはACP認証で渡し、子プロセスやMCPが
継承する環境変数やErrandの設定ファイルには保存しません。

MCPを使う場合は、環境設定の「Gemini CLIのMCP設定ファイル」に設定ファイルの絶対パスを
指定します。そのファイルの`mcpServers`だけを読み、新しいタブでCLIが接続します。
認証方式・自動許可・フック・既存の拡張やスキルは取り込みません。MCPの`trust`も引き継がず、
必要な確認を画面へ戻します。CLIが公開しないMCPフォームやCodex固有の機能は同一にはなりません。
要約はツール・MCPのない別の一時会話で作成し、作業中の会話には混ぜません。
CLI独自のリトライ・API利用上限・料金はCLIとGoogle側の条件に従います。

### APIキーと利用条件

環境設定の「Gemini」で、Google AI Studioで発行したAPIキーを入力し、
「キーを保存」を押します。UbuntuはGNOMEキーリング、macOSはキーチェーンに保存します。
保存後は「保存済み」と表示し、入力欄は消去します。保存済みのキーを再表示しません。
変更する場合は新しいキーを入力して保存し、「削除」でErrand用の保存キーを削除できます。
キーの保存・削除はそのボタンを押した時点で反映し、画面下の設定の「保存」とは別です。
次の新しいタブから利用してください。APIキーの発行は[Google AI Studio](https://aistudio.google.com/api-keys)で行います。

OSの保管庫に保存したキーを優先します。保管庫のロック・アクセス失敗時には接続を止め、
平文のファイルへ自動保存しません。LinuxではlibsecretのGI連携とSecret Serviceが必要です。
キーを保存していない場合は、詳細設定にある従来の方式も利用できます。
環境変数 `GEMINI_API_KEY`、指定したファイルの `GEMINI_API_KEY=...` の順に読み込みます。
ファイル欄が空でも、ホーム内の既定ファイル `.gemini/.env` を使用します。
libsecret連携が未導入の場合も従来の方式は利用できますが、保管庫への保存はできません。
一重・二重引用符と先頭の `export` に対応しますが、シェル展開やコマンド実行はしません。
作業ディレクトリの `.env` は探索しません。キー設定ファイルは自分だけが読み書きできる
権限で管理し、Gitや配布物に含めないでください。既存のキー設定ファイルは変更しません。

既定モデルは `gemini-3.5-flash-lite` です。モデル一覧はCLIから取得します。
Google AI Studioでプロジェクトの利用条件を確認してください。APIはWorkspaceと別枠で、
有料設定のプロジェクトでは従量料金が発生します。無料枠では入力・出力がGoogleの
製品改善に使われる場合があります。Errandから課金を有効にする処理はありません。

依頼文・会話履歴・操作に必要なファイル内容は、CLIを通してGoogleへ送信されます。
中断しても、送信済みのGoogle側の処理や利用量は取り消せません。

Codex・Geminiとも、回答が終了するとコピーボタンの横に「12.3秒 · 初字 3.2秒」のように
所要時間を小さく表示します。送信受付から終了までの総時間と、最初の文字を受信するまでの
時間です。ツールチップでは最初の文字から終了までの内訳も確認できます。
Codexでは接続・ツール実行・承認待ちも含みます。中断・失敗・出力上限は表示で区別します。
1回のお願いに複数の発言がある場合は、最後の回答コピーの横にまとめて表示します。
時間表示は会話・回答のコピーや要約には含めず、永続保存もしません。

仕様の参照先：
[Gemini API](https://ai.google.dev/api/generate-content)、
[料金とデータの取り扱い](https://ai.google.dev/gemini-api/docs/pricing)。
OSが先に受け取るキーはErrandに届きません。GNOMEのワークスペース操作などと
競合する場合は、Errand側で別のキーを設定してください。OSの割り当ては変更しません。

## 操作

以下は既定のキーです。設定したアプリ内のキーは保存後すぐに反映します。

| 操作 | 既定のキー |
| --- | --- |
| 送信 | Ctrl+Enter |
| 前／次の発言へ | Ctrl+Alt+↑／↓ |
| 最初の発言へ | Ctrl+Alt+Shift+↑ |
| 最新へ移動して自動追従 | Ctrl+Alt+Shift+↓ |
| フォーカス移動 | Tab／Shift+Tab |
| 送信済みの依頼を呼び出す（入力欄が空のとき） | ↑／↓ |
| 環境設定 | Ctrl+, |
| 文字を拡大／縮小 | Ctrl++／Ctrl+- |
| 標準の文字サイズ（100%） | Ctrl+0 |
| 新しいタブ | Ctrl+T |
| 左／右のタブへ | Ctrl+PageUp／PageDown、Ctrl+Shift+Tab／Ctrl+Tab |
| タブを閉じる | Ctrl+W |
| アプリ全体を終了 | Ctrl+Q |
| ウィンドウを隠す | Esc |
| 入力欄の先頭／末尾 | Ctrl+Home／End、Ctrl+↑／↓ |

ウィンドウの閉じるボタンは画面を隠す操作です。作業とタブは維持されます。
macOSではDockのアイコン、Finderでアプリを開き直す操作、設定した起動キーで再表示できます。
GNOMEでは拡張のパネルボタンまたは起動キーから再表示します。
新しいタブでは、小仕事の例をランダムに1つ表示します。入力中に自動で切り替わりません。
送信後は実行状況へ切り替わり、エラーやログイン案内は例より優先して表示します。
回答の受信中でも上へスクロールすると末尾への自動追従を止め、末尾に戻ると再開します。
会話欄と状態表示の間の二重上・上・下・二重下ボタンで、最古・前・次・最新へ移動できます。
「あなた」「Codex」の発言を単位に移動し、過去への移動では自動追従を止めます。
最新ボタンは会話の末尾へ移動し、回答の自動追従も再開します。
移動先の発言全体が一度だけ少し薄くなり、薄い状態を0.2秒保ってから約0.6秒で元に戻ります。
キーボードフォーカスは操作ボタンに残します。
再起動にはCtrl+Qで終了してから起動してください。
タブを閉じると、その会話と接続を終了します。閉じた会話は復元できません。

入力欄が空のとき、↑でこのタブの送信済みの依頼を呼び出せます。
呼び出した状態では↑／↓で履歴を移動でき、最新より先へ↓を押すと空欄に戻ります。
編集を始めると通常のカーソル操作に戻ります。履歴はタブを閉じると消え、ファイルの添付は復元しません。

ファイルはドロップするか、依頼文に絶対パスを書いて指定できます。
ドロップ時にはファイル内容を読み込まず、送信時に対象の絶対パスを依頼へ添えます。
会話中のモデル・推論の強さの変更は、次の送信から適用されます。

「会話について」から会話全文のコピーや引き継ぎ用要約の作成ができます。
要約は「引き継ぎ用の要約を作成」で生成し、「要約しました」と表示された後に
状態欄の「要約をコピー」を押してコピーします。生成完了時にクリップボードを変更しません。
コピー後はボタンを隠します。再度必要な場合や会話が更新された場合は要約を作り直します。
回答の生成完了後、末尾のコピーアイコンでその回答全体をコピーできます。
途中の説明と最終回答が分かれて表示されても、アイコンは回答ごとに1つです。
回答の表はタブ区切りになるため、CalcやExcelに行・列を保って貼り付けられます。
本文・引用・コードもまとめてコピーします。

栞アイコンの「定番のお願い」から、名前を付けた依頼文を保存・呼び出しできます。
「今の入力を保存…」で登録し、「管理…」で追加・編集・削除します。
呼び出した依頼文は入力欄に入るだけで、自動送信しません。
入力中の文章や添付ファイルがある場合、または作業中の場合は新しいタブに開きます。
保存するのは名前と依頼文だけです。添付ファイル・モデル・承認方法は保存しません。
定番のお願いはローカルの設定領域に保存し、Errandを終了しても残ります。
要約は別の一時的な会話で生成し、正常完了した場合だけ手動でコピーできるようになります。
要約生成にも通常のモデル利用が発生します。

## 承認と会話の扱い

Codexの会話の作業場所は一時ディレクトリで、初期状態は読み取り専用です。
Codexの初回の承認方法は「自分で承認」です。選択した承認方法を保存し、新しいタブと次回起動に引き継ぎます。
既に開いている別のタブの承認方法は変更しません。変更できるのは作業中でないときです。
「自動レビュー」はすべての操作を無条件で許可する設定ではありません。
MCPサーバーからの確認や質問は、承認方法にかかわらず画面に表示して回答できます。
入力項目のない確認では「このタブでは、同じMCPからの同じ確認を以降許可する」を選べます。
同じMCP名・確認文・スキーマ・付随データに限って許可を記憶し、別の確認や入力付きの質問、
URLの確認は自動回答しません。記憶はタブを閉じるか会話をリセット・再接続すると消え、保存しません。
文字・数値・真偽値・単一／複数選択のフォームと、URLを使う確認に対応します。
URLは表示するだけでは開かず、「ブラウザで開く」を押した場合だけ開きます。
未対応の入力条件を含むフォームでは続行を無効にし、拒否・キャンセルを選べます。
追加権限は、要求された範囲を今回の作業または現在のタブに限って許可できます。
既存ファイルを残すようモデルに指示しますが、書き込み許可後の上書きを技術的に保証するものではありません。

Codexのサンドボックスにはネットワークアクセスを許可しない設定を渡します。
モデルとの通信や、既存のCodex設定に登録したMCPなどのツールまで遮断するものではありません。
ErrandはCodexの認証情報を独自に保存せず、Codexの設定ファイルも編集しません。

Errand独自の会話保存はなく、Codexのスレッドには `ephemeral: true` を指定します。
これはCodexの状態DB・診断ログ・サービス側の記録まで消去する機能ではありません。
必要な会話は、終了前にコピーしてください。

## 表示の制限

Markdownは限定的な対応で、完全なCommonMark互換ではありません。
HTMLや外部画像は実行・自動取得しません。
数式は分数、平方根、上付き・下付き、基本演算記号などに対応します。
行列、独自マクロ、表セル内の数式などは未対応です。
描画できない数式は元の記法を表示します。

開発・ビルド・テストについては [開発ガイド](CONTRIBUTING.md) を参照してください。
